# gld-ion-php

gld-ion-php is an [Amazon Ion](https://amazon-ion.github.io/ion-docs/) serializer
written in PHP 8.3. The runtime and the code generator are PHP. They do not
wrap the Ion PECL extension or any C, C++, or Rust Ion library.
